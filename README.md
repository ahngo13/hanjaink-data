# hanjaink-data — 한자어 뜻풀이 가공본 (CC BY-SA 2.0 KR)

앱 「손글씨 한자사전 (Hanja Ink)」에 들어간 한자어 뜻풀이 데이터입니다.
국립국어원 **우리말샘**의 사전 내려받기 자료를 가공했으며, 원 저작물과 같은
**크리에이티브 커먼즈 저작자표시-동일조건변경허락 2.0 대한민국(CC BY-SA 2.0 KR)** 으로 공개합니다.
앱의 프로그램 코드는 이 저장소에 없으며 이 라이선스의 대상이 아닙니다.

## 출처

- 원 저작물: 국립국어원 「우리말샘」(https://opendict.korean.go.kr) 사전 내려받기 JSON
- 판: 2026-11-04 내려받기 자료 (전체 1,246,000 의미 항목)
- 원 라이선스: CC BY-SA 2.0 KR — https://creativecommons.org/licenses/by-sa/2.0/kr/

## 가공 내용

1. 원어가 **한자로만** 된 표제어의 의미 항목만 골랐습니다(혼종어·외래어 제외).
2. 의미 구분이 「일반어」인 항목만 남겼습니다(방언·북한어·옛말 제외).
3. 표제어 한자 표기와 독음(하이픈·띄어쓰기 기호 제거)이 **둘 다** libhangul `hanja.txt`
   한자어 목록과 일치하는 것만 남겼습니다.
4. 뜻풀이의 HTML 태그와 중복 공백을 지웠고, 용례는 120자 이하인 첫 용례 하나만, 용례 속 표제어 표시
   `{ }` 는 지웠습니다. 같은 표제어 안에서 뜻풀이 문장이 똑같은 의미는 하나만 남겼습니다.
5. 같은 표기·독음 아래 표제어가 여럿이면 우리말샘 어깨번호 순으로 `homograph` 1, 2, … 를 다시 매기고,
   그 안의 의미 번호를 `ord` 1, 2, … 로 다시 매겼습니다.

결과: 한자어 200,151개, 의미 237,225행.

## 파일

`senses.tsv` — UTF-8, 탭 구분, 첫 줄 머리글

| 열 | 내용 |
|---|---|
| hanja | 표제어 한자 (學校) |
| eum | 독음 (학교) |
| homograph | 같은 표기·독음 안의 표제어 번호 |
| ord | 표제어 안의 의미 번호 |
| pos | 품사 (없으면 빈칸) |
| field | 전문 분야 (여럿이면 `·`) |
| gloss | 뜻풀이 |
| example | 용례 (없으면 빈칸) |
| urimalsaem_sense_no | 우리말샘 의미 번호 — `https://opendict.korean.go.kr/dictionary/view?sense_no=<번호>` |
